# Resource Deck

This folder defines the first-pass printable resource / action deck.

## Vertical-Slice Print Minimum

Current first-pass printable minimum: `64` cards total.

Composition rule:

- each `Common` card appears no more than `4` times
- each `Elite` card appears no more than `2` times

One clean way to hit that minimum is:

- `12` Common card definitions at `4` copies each = `48`
- `8` Elite card definitions at `2` copies each = `16`
- total = `64`

The full game's eventual action deck can be much larger, potentially far beyond this minimum. This README tracks the vertical-slice print target rather than a final cap.

## Why 64

This first pass is intentionally sized for a four-player session with:

- `12` starting cards in a `4`-player game
- up to `40` default mid-encounter draws across roughly `10` scenes
- `5` trader cards revealed in a trader scene
- extra reward draws and card-swapping headroom

A `64`-card printable minimum gives some buffer while staying small enough to print.
