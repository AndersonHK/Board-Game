# Resource Deck

This folder defines the first-pass printable resource / action deck.

## Vertical-Slice Print Minimum

Current first-pass printable deck: `80` cards total.

Composition rule:

- each `Common` card appears `4` times
- each `Elite` card appears `2` times
- each `Rare` card appears `2` times, if a later card uses that word

Current Edition 0 composition:

- `15` Common card definitions at `4` copies each = `60`
- `8` Elite card definitions at `2` copies each = `16`
- `2` Rare card definitions at `2` copies each = `4`
- total = `80`

The full game's eventual action deck can be much larger, potentially far beyond this Edition 0 print count. This README tracks the vertical-slice print target rather than a final cap.

## Why 64

This first pass is intentionally sized for a four-player session with:

- `12` starting cards in a `4`-player game
- up to `40` default mid-encounter draws across roughly `10` scenes
- `5` trader cards revealed in a trader scene
- extra reward draws and card-swapping headroom

The current `80`-card printable deck uses the former class-reference blank slots as resource overflow, giving more draw and trader headroom while staying within the existing `16` atlas sheets.
