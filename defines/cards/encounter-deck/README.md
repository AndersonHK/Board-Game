# Encounter Deck

This folder defines the first-pass printable encounter deck for the vertical slice.

## Vertical-Slice Print Minimum

- at least `8` random encounters
- `1` scripted mid-game ordeal
- `1` scripted final ordeal

These counts are minimum printable content goals for the vertical slice, not a global cap on the full game's eventual encounter library.

## Runtime Use

Random encounters are shuffled together for a session.

Scripted ordeals are not shuffled into the random deck. They are resolved only when the quest tells the table to reveal them.
