# Encounter Deck

This folder defines the first-pass printable encounter deck for the vertical slice.

## Vertical-Slice Print Minimum

- at least `8` random encounters
- `1` scripted mid-game ordeal
- `1` scripted final ordeal

These counts are minimum printable content goals for the vertical slice, not a global cap on the full game's eventual encounter library.

## Runtime Use

Random encounters are shuffled together for a session.

Scripted ordeals are not shuffled into the random deck. They are resolved only when the quest tells the table to reveal them.

## Reveal Text

Drawing an encounter card is the reveal. Players immediately see all text on that card, so the card should not split setup into a separate hidden or second-stage spawn field.

Use `Reveal Text` for the immediate scene setup, including any monsters, hazards, allies, or persistent cards that enter play when the encounter is drawn.

## Print-Fit Discipline

Encounter cards need room for a title, functional text, and a flavor image. Keep encounter-only rules short, and do not repeat rules already printed on spawned creature, artifact, or enchantment cards.

As a working production target, keep the combined reveal, scene, clear, reward, failure, rules, and flavor text near `75` words or less whenever possible. Longer text should earn its space by being owned by the encounter itself, such as trader resolution.
