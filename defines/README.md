# Defines

This folder is reserved for canonical rule defines, numeric baselines, reusable data tables, and other settled mechanical references.

Current canonical files:

- [core-rules.md](./core-rules.md): baseline hand rules, standard round flow, and escalation timing.
- [creature-deck.md](./creature-deck.md): the formal creature deck definition and its role in scene spawning.
- [cards/README.md](./cards/README.md): canonical vertical-slice card-data format, folder layout, and template index.

Until a value or subsystem is tested enough to feel durable, keep exploratory material in temporary playtest packages instead of promoting it here.

Promotion policy:

- Playtest findings can propose canon changes.
- Nothing in `temp/playtests/` is canon by itself.
- No playtest finding should be promoted into `defines/` without explicit user approval.
