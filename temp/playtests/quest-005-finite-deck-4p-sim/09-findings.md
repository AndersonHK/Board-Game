# Quest 005 Findings

Evidence files: [simulation log](./07-simulation-log.txt), [rulings log](./08-rulings-log.txt), [source map](./00-source-map.md)

## What Held Up

- The current canon is finally strong enough to support a real finite-deck run. This pass no longer needed the older prototype action catalog.
- The quick-start class kit still reads well in motion. Warrior burst, Wizard storage plus shielding, and Cleric rescue support all mattered without extra subsystem scaffolding.
- The quest thresholds produced a clean phase structure: early setup, midpoint tax, late hostile pressure, then the uncapped final ordeal.
- Real `Glory Points` created much better selfish tension than the old spotlight proxy. Kael and Brin felt like different kinds of selfish immediately.
- Immediate scene ending on clear produced healthier pacing than letting solved rooms continue through the rest of the round would have.

## What Broke Or Stayed Ambiguous

- The live card data and deck READMEs are no longer internally consistent. Resource counts say `72` in practice, not `64`, and encounter files now offer `9` random encounters even though the quest still says `8`.
- Human players still do not have a printed hostile-claim procedure, even though prestige scoring and two agenda cards depend on one.
- Non-combat tests still lean on hidden assumptions. Cards tell players to cut chains, pick gates, or secure crossings, but the base success number is still inferred rather than taught.
- `Current claimant` is still invisible jargon outside the encounter files that use it.
- Ownership is still muddy for party-controlled permanents like `Blessing Brazier`, which matters the moment scoring asks for player-owned field cards.

## What This Run Suggests Should Be Defined Next

- Define the hostile/blocking claim procedure in a player-facing scoring section.
- Reconcile the resource-deck total so the README and card-file counts agree.
- Reconcile the encounter-deck random-count promise so the quest card and encounter file pool match.
- Add one explicit sentence to the quick start for what happens when a scene clears before the end of the round.
- Add one explicit sentence to the quick start for default non-combat test target numbers.
- Define `current claimant` anywhere it is expected to influence a discard or reward.
- Clarify whether party-controlled cards can ever become player-owned for prestige.

## What This Run Suggests Should Be Adjusted

- `By My Grace` looks much harder than the other dealt agendas in the current encounter mix. With only one clear save-centric scene in this run, Tamsin was effectively drawing dead on agenda pace very early.
- The finite resource deck felt healthier than the old prototype pool, but it also made greed choices more legible. That is good pressure and worth keeping.
- Threshold-5's reward-draw tax worked well because it punished greed without invalidating reward scenes. That feels close to promotion-ready once its timing is written more explicitly.

## Promotion Call

- Strong candidate for future canon: immediate scene end once the clear condition is met.
- Strong candidate for future canon: default `4+` for non-combat tests when no number is printed.
- Strong candidate for future canon: a player-facing hostile-claim rule for prestige and agenda scoring.
- Not ready for promotion yet: any ownership rule for party-controlled permanents, because only one artifact of that type has been stress-tested so far.
