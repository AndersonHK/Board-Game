# Printed-Package Findings Before Deferred Reading

## What The Printed Package Taught Well

- Setup was strong. The quest card, quickstart, bundle list, and widget definitions made the 3-player starting HP, starting hand size, escalation tracker, decks, dice, and token use easy to reconstruct.
- The round structure was playable. The table could reveal scenes, take two action turns, run enemy turns, draw once per round, and resolve end-of-round effects without needing outside rules.
- Shared party state was physically clear. Party HP, escalation, shields, damage tokens, player score piles, trader stock, and party-controlled cards all had obvious table homes.
- Combat basics were clear enough. HP, attack values, shields, defeated creatures, claims, Warrior rewards, and enemy priority mostly worked from printed text.
- Scoring was understandable once score piles were maintained. Claimed hostile/blocking cards, hand value, field value, and agenda rewards gave a concrete endgame tally.

## What The Printed Package Failed To Teach Reliably

- Non-combat obstacles are under-defined. Cracked Causeway says spend 1 action to secure the crossing, Smoke-Flood Gallery says vent with a non-combat test, Iron Gate and Rusted Chains have HP, and utility cards grant bonuses to tests. The package does not clearly say when obstacles use HP, tests, automatic actions, or player choice.
- Card-loss instructions need selectors. "Lose 1 card," "one player discards," and similar phrases often do not say whether the affected player chooses, the active player chooses, fixed order chooses, or the discard is random.
- Trader timing is unclear. The rules say each player gets one interaction, but not whether that interaction costs an action or happens outside the action structure.
- Reward timing is inconsistent. Some rewards happen when cleared, some must be claimed, and some use "claimant" without fully distinguishing current claimant, active player, reward claimant, and last-hurdle clearer.
- Threshold 5 is hard to apply. It asks for the first player each scene to gain an extra draw from encounter Reward Text, but simultaneous rewards and non-draw hand movement need explicit handling.
- Enemy targeting still needs a tie policy. "Legal friendly creature first" works, but if several friendly creatures are legal, the table has no printed target-selection rule.
- Final-ordeal timing is not fully teachable. The package says to alternate extra player turns and enemy turns after Enemy Turn 2, but not whether "player turn" means one player, all players, fixed order, or chosen order, nor whether round-end effects continue.
- Active and exhaust reset timing needs one more physical convention. The widget sheet says used markers can track these, but the quickstart does not consistently say when all once-per-scene, once-per-turn, used-this-round, and exhausted markers are removed.
- Party HP maximum is absent from the quickstart. The bundle manifest notes the gap and a recommended default, but players using only the quickstart and cards would not know whether healing can exceed starting HP.
- Heartfire Dragon's d3 is undefined. The package includes only a d6, and the dragon card uses 1d3 damage without teaching how to roll it.
- Repeated enemy active abilities need a cadence rule. The final boss and Warden imply they can use active abilities and still attack, but do not say whether actives are once per enemy turn, once per round, or otherwise limited.

## Temporary Rulings That Kept The Game Moving

- Default non-combat tests succeeded on 4+ if no number was printed.
- Relevant utility cards could clear matching obstacles by test, even when those obstacles also had HP.
- A player affected by card loss chose which card to lose unless the card named another chooser.
- Trader interactions consumed actions.
- Party HP was capped at 18.
- Threshold-5 simultaneous reward taxes resolved in fixed player order.
- d3 was rolled as d6 divided by two, rounded up.
- Final extra player turns meant one action per player, followed by one enemy turn.

## Suggested Later Adjustments

- Add a compact "obstacles and tests" rule to the quickstart, with examples for doors, chains, crossings, smoke, and artifacts with HP.
- Add a universal discard selector rule.
- Clarify whether trader interactions are actions.
- Define reward claimant/current claimant/last clearer in one place and use those exact terms on encounter cards.
- Add a threshold-5 reminder that simultaneous rewards resolve in fixed player order, or rewrite it to avoid simultaneous ambiguity.
- Add a printed d3 instruction to the Dragon card or quickstart.
- Define final-ordeal extra turns and whether round-end effects continue during them.
- Move the party HP maximum recommendation from production-gap text into the player-facing quickstart.
