# Research: Betrayal at House on the Hill

This note captures the parts of Betrayal at House on the Hill that seem relevant to the current project. The design brief that references this research lives in [../design/core-concept.md](../design/core-concept.md). The research index lives in [research-index.md](./research-index.md).

## Why This Matters

The user cited Betrayal at House on the Hill to signal interest in its gameplay dynamic. The most relevant design takeaway is not the horror theme itself, but the way the game transitions from open-ended cooperative exploration into a suddenly recontextualized conflict state.

## Key Insights

1. The early game is structurally simple: players explore, reveal content, and build the play space as they go.
2. The board grows through modular tile addition, which creates replayability and a sense of discovery.
3. A specific trigger system pushes the game from one mode into another; in common rules summaries this is the "haunt" moment tied to omen accumulation.
4. After the trigger, information splits. Different sides read different instructions and can no longer act with full shared knowledge.
5. The trigger does not just increase difficulty; it changes the game's social and strategic meaning.
6. The system gains a lot of drama because ordinary early-game actions are later reinterpreted by the reveal.

## Design Relevance For This Project

- A board game can stay simple in its teach if the complexity arrives as a mode shift rather than all at once.
- A reveal point can make the early rounds feel like setup and social reading, not just resource collection.
- If this project wants semi-cooperative play, hidden objectives, or a betrayal turn, Betrayal is a good model for how to pivot the table cleanly.
- Even if this project does not use a literal traitor, a midgame state change could still reframe incentives and create drama.

## Cautions

- Betrayal is famous for drama and variety, but also for uneven scenario balance and occasional rules awkwardness. That suggests using the phase-shift lesson without importing too much scenario-specific complexity.
- For a one-week class project, modularity and surprise are attractive, but content volume must stay tightly constrained.

## Candidate Adaptations

- a shared escalation trigger rather than a hidden-traitor reveal
- a small scenario deck that changes global rules at a threshold
- a cooperative early phase that becomes openly competitive later
- a public event reveal that causes alliances to reorganize
