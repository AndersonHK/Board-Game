# Research: Hearthstone Hero Powers

This note captures the parts of Hearthstone hero powers and adjacent hero-asymmetry designs that seem relevant to the current project. The design brief that references this research lives in [../design/core-concept.md](../design/core-concept.md). The class design that references this research lives in [../design/class-archetypes.md](../design/class-archetypes.md). The research index lives in [research-index.md](./research-index.md).

## Why This Matters

The user pointed to Hearthstone hero skills as a model for lightweight class differences. The relevant lesson is not collectible-card complexity; it is the way a very small repeatable power can shape an entire play pattern.

## Key Insights

1. A hero power can be short, stable, and always available, which makes it easy to teach and easy to remember.
2. Even when the text is small, a repeatable power changes how a player values tempo, resources, and synergies across the whole game.
3. A passive bonus plus one active button is often enough to make a hero feel strategically distinct.
4. In Battlegrounds and special hero modes, hero powers often define an archetype by nudging drafting, positioning, timing, or risk tolerance rather than by replacing the whole ruleset.
5. Good hero powers create an identity that is visible in actual play, not just in flavor text.

## Particularly Relevant Details

- Blizzard's Battlegrounds descriptions emphasize that each hero power changes how players recruit, battle, and strategize.
- Blizzard's Whizbang's Heroes description explicitly frames a hero as a combination of a unique Hero Power and a corresponding Passive effect.
- This matches the user's stated desire for each class to likely have at least one active and one passive trait.

## Design Relevance For This Project

- Each class can probably be expressed as one passive and one active ability.
- The active should be reusable or consistently relevant, not a one-time trick.
- The passive should shape incentives every round.
- The class identity should appear through ordinary play decisions, not only rare combo states.

## Candidate Adaptations

- once-per-turn or once-per-round active abilities
- active abilities that convert one resource into another in a class-specific way
- passives that reward aggression, preservation, or cooperation respectively
- simple reminder text that changes evaluation of otherwise shared cards or actions

## Cautions

- Repeatable powers must be easy to track in a physical game state.
- If the active ability is too strong, it can dominate the rest of the system.
- If the passive is too invisible, the class will feel cosmetic.
